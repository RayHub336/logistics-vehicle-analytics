# logistics-vehicle-analytics
Practicar las tareas habituales de la ingeniería de software. Aumentar y complementar habilidades en el campo de los datos. Creación y gestión de entornos virtuales de Python y el desarrollo de una aplicación web.  Proyecto basado en Venta de coches.

# Dashboard de Vehículos Usados

Esta es una aplicación web interactiva desarrollada en Python utilizando Streamlit.

## Funcionalidades
- Visualización de la distribución del kilometraje de los vehículos (Histograma).
- Análisis de la relación entre precio y kilometraje (Gráfico de Dispersión).

## Cómo ejecutar localmente
1. Clonar el repositorio.
2. Instalar dependencias: `pip install -r requirements.txt`
3. Ejecutar la app: `streamlit run app.py`
